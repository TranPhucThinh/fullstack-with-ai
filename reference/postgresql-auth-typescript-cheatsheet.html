Kết nối PostgreSQL (Bài 12)

pg.Pool + parameterized query 
import pg from 'pg'
import { loadEnvFile } from 'node:process'
loadEnvFile()   // nạp .env vào process.env
const pool = new pg.Pool() // đọc PG* env vars
const { rows, rowCount } = await pool.query(
  'SELECT * FROM users WHERE id = $1', [id]
)

$1, $2 (không nối chuỗi) → chống SQL injection. rowCount = số dòng bị ảnh hưởng.

Index & EXPLAIN (Bài 13-pro)

Chứng minh index bằng EXPLAIN 
-- trước: Seq Scan (quét cả bảng)
EXPLAIN ANALYZE SELECT * FROM enrollments WHERE user_id = 1;
CREATE INDEX idx_enrollments_user_id ON enrollments(user_id);
-- sau: Index Scan (chỉ đọc dòng khớp)

PK tự có index, cột khóa ngoại thì KHÔNG — phải tạo thủ công khi JOIN/lọc thường xuyên. Index = đọc nhanh đổi lấy ghi chậm.

JOIN & thống kê (Bài 13/13-pro)

LEFT JOIN + GROUP BY + HAVING 
SELECT c.title, COUNT(e.user_id) AS so_hoc_vien
FROM courses c
LEFT JOIN enrollments e ON e.course_id = c.id
GROUP BY c.id, c.title
HAVING COUNT(e.user_id) = 0;

LEFT JOIN giữ cả khóa 0 người học (INNER JOIN làm nó biến mất). WHERE lọc trước khi gộp; HAVING lọc sau GROUP BY.

Migration, timestamps, soft delete (Bài 13-pro)

  • Migration = "git cho schema": mỗi thay đổi là 1 file version, chạy theo thứ tự → tái lập được môi trường.
  • created_at/updated_at TIMESTAMPTZ DEFAULT now().
  • Soft delete: thêm deleted_at TIMESTAMPTZ, truy vấn lọc deleted_at IS NULL — khôi phục được, giữ lịch sử.
  • Surrogate key (SERIAL id) làm PK; khóa tự nhiên (email) đặt UNIQUE riêng.

Auth — bcrypt + JWT (Bài 14)

Hash + token + verify 
import bcrypt from 'bcrypt'
import jwt from 'jsonwebtoken'
const hash = await bcrypt.hash(pw, 10)   // cost factor
const ok = await bcrypt.compare(pw, hash)
const token = jwt.sign({ userId }, SECRET, { expiresIn: '1h' })
const payload = jwt.verify(token, SECRET) // sai secret → throw

Gửi token: Authorization: Bearer <token>. Hash một chiều, JWT stateless.

Decorators & Utility types (Bài 17)

Decorator method/class + factory — nền tảng NestJS 
// Method decorator — (target, propertyKey, descriptor)
function log(target, propertyKey, descriptor) {
  const original = descriptor.value
  descriptor.value = function(...args) { console.log(propertyKey, args); return original.apply(this, args) }
}
// Class decorator factory — hàm NHẬN tham số, TRẢ VỀ decorator
function Register(name) { return ctor => { registry[name] = ctor } }
@Register('CalcService') class CalcService { @log add(a, b) { return a + b } }

// Utility types — dẫn xuất từ 1 interface
type NewCourse = Omit<Course, 'id'>        // bỏ field
type Patch = Partial<Course>          // mọi field optional
type Card = Pick<Course, 'id'|'title'> // chỉ giữ 2 field
type Frozen = Readonly<Course>       // cấm sửa

⚙️ Cần experimentalDecorators: true. @Register('x') = DI container thu nhỏ của NestJS. tsx tôn trọng include → file dùng decorator phải nằm trong src/.
