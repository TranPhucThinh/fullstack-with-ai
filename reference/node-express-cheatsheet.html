HTTP Server Node thuần (Bài 06)

Khởi tạo server 
import { createServer } from 'node:http'
const server = createServer((req, res) => {
  // req: IncomingMessage (Readable) · res: ServerResponse (Writable)
  res.writeHead(200, { 'Content-Type': 'application/json' })
  res.end(JSON.stringify({ ok: true }))
})
server.listen(4000, '0.0.0.0')

req đọc body qua data/end; res.end() bắt buộc gọi đúng 1 lần.

Routing & Query (Bài 07)

Bảng route + parse query 
const routes = [
  { method: 'GET', pattern: /^\/api\/courses$/, handler: list },
  { method: 'GET', pattern: /^\/api\/courses\/(\d+)$/, handler: get },
]
// query: url.search.slice(1) -> URLSearchParams

→ Express gói gọn: app.get('/api/courses/:id') + req.params/req.query.

Express Routing (Bài 09–10)

Route + middleware cơ bản 
const app = express()
app.use(express.json())
app.get('/api/courses/:id', (req, res) => {
  res.json({ id: req.params.id })
})
app.post('/api/courses', (req, res) => {
  res.status(201).json(req.body)
})

req.query · req.params · req.body (cần express.json) · res.status().json().

Middleware (Bài 11)

Middleware thường + error-handler 
// Middleware thường — 3 tham số, phải gọi next()
app.use((req, res, next) => {
  console.log(req.method, req.url)
  next()
})

// Error-handler — ĐÚNG 4 tham số
app.use((err, req, res, next) => {
  res.status(500).json({ error: 'Internal Server Error' })
})

Thứ tự quan trọng: cors() đầu, error-handler cuối. Quên next() → request treo.

CORS (Bài 11)

Bật CORS cho frontend 
import cors from 'cors'
app.use(cors()) // thêm header Access-Control-Allow-Origin vào mọi response

Đặt ĐẦU TIÊN để header CORS phủ cả response lỗi. Production nên giới hạn origin, không dùng *.
