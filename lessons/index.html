Lộ trình Senior Backend — Node.js / NestJS

Học từ gốc lên: HTTP → Node thuần → Express → TypeScript → NestJS → Production-grade → Kiến trúc senior. Mỗi bài đóng góp một mẩu chạy được vào dự án e-learning.

Cách học: Bạn coi như chưa biết gì về backend — mỗi bài dạy MỘT thứ, nhỏ, làm xong nhanh, có win cụ thể. Dự án song song E-Learning Platform lớn dần theo từng bài. Chấm bài = đọc code thật + chạy test thật. Hỏi tôi (người dạy) bất cứ điều gì chưa rõ — ở cuối mỗi bài.
