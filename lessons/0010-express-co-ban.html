1. Cài Express vào dự án

Express là package npm. Cài vào dependencies (cần ở production), và @types/express vào devDependencies (chỉ cần khi phát triển, để TypeScript hiểu type của Express).

Terminal — từ thư mục elearning-backend/ 
# Cài Express (chạy ở production) + type cho TypeScript (chỉ lúc phát triển)
npm install express
npm install -D @types/express

2. Viết lại server bằng Express

Thay toàn bộ nội dung src/server.ts bằng code dưới đây. Đối chiếu từng phần với code cũ:

Code tay (bài 07–08)Express (bài này)
createServer(...) + vòng for match routesconst app = express() + app.get()/app.post()
parseQuery (URLSearchParams)req.query — có sẵn
readBody (gom chunk + JSON.parse)app.use(express.json()) → req.body
sendJson (writeHead + end)res.json() / res.status(...).json()

src/server.ts — viết lại bằng Express (thay toàn bộ file) 
import express, { type Request, type Response } from 'express'
import { courses, createCourseId } from './courses.js'

const app = express()
app.use(express.json()) // middleware: đọc + parse body JSON — chính là readBody bạn tự viết ở bài 07

// GET /api/courses?limit=1 — trả danh sách (hỗ trợ limit)
app.get('/api/courses', (req: Request, res: Response) => {
  const limit = Number(req.query.limit ?? courses.length) // req.query thay parseQuery
  res.json(courses.slice(0, limit)) // res.json thay sendJson
})

// GET /api/courses/:id — trả 1 khóa học
app.get('/api/courses/:id', (req: Request, res: Response) => {
  const course = courses.find((c) => c.id === Number(req.params.id)) // req.params.id thay match[1]
  if (course) res.json(course)
  else res.status(404).json({ error: 'Course not found' })
})

// POST /api/courses — validation thiếu title -> 400
app.post('/api/courses', (req: Request, res: Response) => {
  const { title, price } = req.body ?? {} // req.body có sẵn nhờ express.json()
  if (!title || typeof title !== 'string') {
    res.status(400).json({ error: 'title là bắt buộc (string)' })
    return
  }
  const id = createCourseId()
  const course = { id, title, price: Number(price) }
  courses.push(course)
  res.status(201).json(course)
})

// PORT đọc từ env — giữ nguyên bài 08
const PORT = Number(process.env.PORT ?? 4000)
app.listen(PORT, () => {
  console.log(`✅ Express running at http://localhost:${PORT}`)
})
💡 Vì sao không cần HOST nữa?

Code cũ có server.listen(PORT, HOST, ...) với HOST = '0.0.0.0'. app.listen(PORT) của Express mặc định lắng nghe mọi interface (tương đương 0.0.0.0) — nên không cần khai báo HOST. Đây là một ví dụ Express đã "đóng gói" quyết định mặc định hợp lý.

3. Chạy và verify bằng curl

Terminal 1 — chạy server 
npm run dev
Terminal 2 — curl 6 trường hợp (giống hệt bài 07) 
# 1. GET list — trả 2 khóa học
curl -s http://localhost:4000/api/courses

# 2. GET ?limit=1 — trả 1 khóa học
curl -s "http://localhost:4000/api/courses?limit=1"

# 3. GET /:id=2 — trả khóa học id 2
curl -s http://localhost:4000/api/courses/2

# 4. GET /:id=99 — 404
curl -s http://localhost:4000/api/courses/99

# 5. POST thiếu title — 400
curl -s -X POST -H "Content-Type: application/json" -d '{"price":100}' http://localhost:4000/api/courses

# 6. POST hợp lệ — 201, trả khóa học mới
curl -s -X POST -H "Content-Type: application/json" -d '{"title":"Express cơ bản","price":300000}' http://localhost:4000/api/courses

⚠️ Lưu ý khi chạy

Nếu cổng 4000 bị chiếm (bài 08 bạn đã gặp EADDRINUSE), đổi cổng: PORT=4321 npm run dev. Và nhớ: npm run dev dùng tsx watch — sửa file là tự reload, không cần chạy lại.

4. Middleware — bạn vừa dùng cái đầu tiên

Dòng app.use(express.json()) chính là middleware — khái niệm bài 09. Nó chạy trước mọi route handler, đọc body từ stream, parse JSON, rồi gắn kết quả vào req.body và gọi next() để request đi tiếp. Nếu bạn quên dòng này, req.body sẽ là undefined — POST sẽ vỡ. Hãy thử xóa dòng đó và chạy lại POST để thấy sự khác biệt.

💡 Vì sao gọi là "đường ống"?

Request đi qua từng middleware theo thứ tự khai báo: express.json() → route handler. Mỗi mắt xích làm một việc rồi chuyển tiếp bằng next(). Bài 11 sẽ viết middleware của riêng bạn (log, error, CORS).

5. Câu hỏi tư duy (bắc cầu sang bài sau)

Bạn vừa dùng middleware có sẵn express.json(). Nhưng trong dự án thật còn nhiều việc dùng chung: ghi log mỗi request, bắt lỗi để không crash server, cho phép frontend gọi từ domain khác (CORS).
